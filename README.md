## 安装
1. 确保使用的是最新版汉化MAS, 且已安装前置子模组.
2. 请从[Release](https://github.com/EATomb-MAS-Submods/EATomb-Location-Packs/releases)处下载最新版本.
3. 确保游戏处于关闭状态后, 将zip中的同名文件夹合并到您的`DDLC`/`MAS_CN001***/Monika After Story`文件夹内, 或者是`DDLC.exe`/`MAS.exe`所在的位置, 即MAS根目录.
  > 不能直接将文件解压进Submods文件夹! 打开压缩包, 并根据文件夹结构合并.
  > - 若您使用Windows系统, 复制压缩包内的`game`文件夹后, 将指针移动到MAS根目录的空白处进行粘贴, 即可完成合并操作.
  > - 若您使用MacOS系统, 拷贝压缩包内的`game`文件夹后, 将指针移动到MAS根目录的空白处进行粘贴, 选择`合并`即可.
  > - 或点击Finder窗口右上角的`操作` -> `粘贴项目`, 选择`合并`即可.
